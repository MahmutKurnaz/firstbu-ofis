# F3 — Canlılık ve hareket · uygulama planı

Tasarım: `docs/superpowers/specs/2026-10-28-firstbu-dunya-design.md` (F3). Testleri ayrı bir Sonnet 5.5 ajanı yazar.

## Kapsam

1. **Seni arıyor (cadde):** Koltuğunda değilken soru soran (`needs_input`) ajan masasından kalkar, nerede
   olursan ol yanına yürür, önünde durup sana döner. **E** terminalini açar. Cevaplayınca masasına döner. Sen
   uzaklaşırsan peşinden gelir. İşi biten (`done`) ajan ise eskisi gibi kafede, koltuğunun önünde sıraya girer.
   Koltuğunda oturuyorsan herkes kafedeki sıraya girer (kale ve istasyon değişmez: yalnızca `cadde` stili).
2. **Alt ajan hayaletleri:** Claude Code `SubagentStart` / `SubagentStop` hook'ları. Bir ajanın çalışan her alt
   ajanı, masasının yanında yarı saydam küçük bir figür olarak görünür, üstünde türü yazar (`Explore`…).
   Bütün haritalarda çalışır.
3. **Cadde canlılığı:** Caddenin güneyinde yürüyen birkaç yaya (dekor) ve kafe tezgâhında kahve buharı.

## Arayüzler

- `src/shared/protocol/workers.ts`: `WorkerInfo.subagents?: { id: string; type: string; at: number }[]`.
- `src/server/workers/subagents.ts` (yeni):
  - `MAX_SUBAGENTS = 6`.
  - `noteSubagent(info, event, payload, now?): boolean` (değiştiyse true):
    - `SubagentStart`: `{ id: payload.agent_id || üretilen, type: payload.agent_type || 'alt ajan' (≤ 40), at: now }`
      ekler. Aynı id iki kez eklenmez. En çok 6 tutar (en eskisi düşer).
    - `SubagentStop`: o id'yi siler. id yoksa aynı türden en eskisini siler.
    - `Stop` ve `SessionStart`: listeyi boşaltır.
    - Liste boşalınca alan silinir (`undefined`).
- `src/server/providers/claude.ts`: hook listesine `SubagentStart`, `SubagentStop`. `claudeHook` olayları
  `noteSubagent`'a verir, değişirse `h.emit()`.
- `src/client/world/court.ts`:
  - `export function seekSpots(anchor: { x; z; rotY }, count): { x; z; rotY }[]`: `anchor.rotY`'nin baktığı
    yönde 1,7 m önde, 1,1 m arayla yan yana. Her biri anchor'a döner.
  - `Court.line(waiting: readonly string[], asking?: ReadonlySet<string>)`.
  - `Court.follow(anchor | null)`: `asking`'deki ajanlar `anchor` varken yanına gelir. Anchor 2,5 m'den fazla
    kayınca yeniden yola çıkarlar. `null` olunca kafedeki sıraya dönerler.
  - `Court.seeking(id): boolean`.
  - Yanına gelen ajanlar için 4 etkileşim noktası (kind `desk`, `deskId` o ajanın masası).
- `src/client/features/ghosts/` (yeni özellik): `logic.ts` → `ghostSlots(n): { dx: number; dz: number }[]` (masa
  çerçevesinde, koltuğun arkasında yay çizerek, n ≤ 6). `index.ts` → `installGhosts(ctx)`.
- `src/client/world/cadde/passersby.ts` (yeni): `LANES`, `strollAt(lane, t): { x; z; heading }` (saf). Yayalar
  `World.update` içinde yürür.
